FOODNESIA
=========
Demo website pemesanan makanan Indonesia.

File:
- index.html
- style.css
- script.js
- data.json
- favicon.svg

Cara menjalankan:
1. Extract ZIP.
2. Buka index.html di browser, atau upload seluruh isi folder ke GitHub Pages.
3. Untuk aplikasi production, hubungkan frontend ke backend/API untuk akun, database restoran, pembayaran, order, dan driver tracking.

Catatan:
Website ini adalah prototype frontend. Checkout dan keranjang berjalan di browser menggunakan localStorage; belum memproses pembayaran atau delivery sungguhan.
